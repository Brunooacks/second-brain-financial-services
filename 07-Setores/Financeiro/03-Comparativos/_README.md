# 🧭 03-Comparativos — Benchmarking

Dois tipos de benchmarking, em subpastas:

- **`Jornadas/`** — De-Para de jornada (jornada × players), o coração do discovery. **A rotina noturna grava aqui.** Índice em [[_Indice-Jornadas]].
- **`Produtos/`** — Comparativos produto a produto (ex: Conta PJ), cruzando players.

Instituições (portfólio + estratégia de ataque de cada player) ficam em [[01-Instituicoes]]. Fichas de produto ficam em `02-Produtos/` por categoria.
